Kebijakan Privasi (Privacy Policy)

Nama Aplikasi: n8n Calendar Bot
Terakhir diperbarui: 14 September 2026

Kebijakan Privasi ini menjelaskan bagaimana n8n Calendar Bot ("Aplikasi", "Kami") mengumpulkan, menggunakan, dan melindungi informasi serta data pengguna saat terhubung dengan Layanan Google API. Kami berkomitmen untuk menjaga privasi data Anda dengan standar keamanan yang tinggi.

1. Data yang Kami Akses dan Kumpulkan

Melalui integrasi Google OAuth, Aplikasi kami meminta izin untuk mengakses data berikut dengan prinsip kebutuhan minimum (least privilege):

  • Google Calendar API: Digunakan untuk membaca aktivitas/agenda di kalender Anda serta membuat jadwal atau acara baru secara otomatis sesuai dengan alur kerja (workflow) n8n Anda.
  • Google Spreadsheet API: Digunakan dalam mode baca (view mode) untuk membuka dan membaca data dari file spreadsheet tertentu yang Anda tentukan sebagai sumber data otomatisasi.

2. Penggunaan Data

Semua data yang diakses dari akun Google Anda hanya diproses secara real-time untuk menjalankan fungsionalitas utama otomatisasi n8n Calendar Bot. Kami tidak menyimpan salinan data kalender maupun spreadsheet Anda di server eksternal kami secara permanen.

3. Pembagian Data ke Pihak Ketiga

Kami menegaskan bahwa Kami tidak membagikan, menyewakan, atau menjual data pengguna Anda kepada pihak ketiga mana pun untuk tujuan pemasaran, periklanan, atau komersial. Data Anda sepenuhnya berada di bawah kendali Anda sendiri.

4. Perlindungan dan Keamanan Data

Aplikasi ini mematuhi Kebijakan Data Pengguna Layanan Google API (Google API Services User Data Policy). Semua transmisi data antara aplikasi dan server Google dilindungi menggunakan enkripsi standar industri (HTTPS/TLS). Kontrol penuh otorisasi token OAuth dipegang langsung oleh pengguna melalui instans n8n Anda.

5. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Setiap perubahan akan diperbarui pada halaman ini dengan merevisi tanggal "Terakhir diperbarui" di bagian atas dokumen.

6. Kontak Developer

Jika Anda memiliki pertanyaan mengenai penggunaan data atau Kebijakan Privasi ini, Anda dapat menghubungi kami melalui email pengembang yang terdaftar di Google Cloud Console Anda.
